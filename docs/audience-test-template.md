# 約五位觀眾研究：待實施腳本與空白表

**狀態：尚未招募、尚未實施、沒有受測結果。** 本文件是研究準備，不是成果。適合 18–30 歲、無需日本史背景的觀眾，自願參與，可隨時停止；不收集姓名、學號或非必要個人資料。研究前依課程要求另確認同意與資料處理方式。

## 執行方式

1. 說明是在測試展覽是否清楚，不是考參與者；詢問是否同意匿名記錄操作與回答。錄音／錄影必須另取得明確同意，否則只記筆記。
2. 請由首頁自行找一件感興趣的作品，說出第一眼注意的地方；研究者不指示正確路線。
3. 請觀賞《月之岬》，說出兩個可見細節，讀解說後說明哪一點來自館方、哪一點是自己的推測。
4. 請比較《兩國花火》和《御廄河岸》：各指出一項線索，說明遊賞和工作如何出現在夜晚。不要要求背職業或鐘點。
5. 請做活動二的短路線，可提示、略過、不寫反思；觀察是否能回到作品介紹、看清焦點、理解錯誤回饋，再找到手帖。
6. 詢問「有哪一段讀不懂或不相信？」「哪個細節改變了你對夜晚的想法？」「哪個操作讓你停住？」不暗示預期答案。
7. 若使用自己的裝置，事後詢問是否要清除本機進度；不擅自複製個人反思。不蒐集無關瀏覽資料。

記錄操作、研究者提示與參與者原話分欄；不把研究者推論寫成參與者說法。時間只記實測，不預填平均分鐘數。
